# examples

`case/` is a complete case file for an **invented** patient: every name, date and value is fictional. Use it to see
what the reports look like before you have your own case, and as a starting point for writing one.

```bash
python -m reports build --case examples/case --out examples/out
```

It builds every report: the full treatment timeline and its charts (interactive pages and PDFs), the treatments
table, pathology, blood counts, weight and function, medications, the disease overview, open questions and the
emergency summary, then the source audit (`source_audit_<date>.pdf`).

- `case/notes/` holds fictional de-identified visit notes with lab tables, vital signs and medication lists
  (generated by `make_notes.py`), so every report has data. A real case's `notes_dir` is the pipeline's
  `filtered/notes`.
- `case/citations.yaml` cites the example's statements from those notes (found with `reports audit --suggest`), plus
  a few hand-made entries that show the other statuses: family report, partly grounded, no source yet.

`out/` is git-ignored.
